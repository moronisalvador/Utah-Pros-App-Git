What's new on this screen

  • Job mode. Today the Hub only knows how to be an appointment. Open it with nothing running and it has nothing to show.
  • Tappable name and claim #. The customer and the claim become the way in — no pills.
  • Call · Text · Docs · Notes at the top instead of buried in a bottom menu.
  • Dry Logs, Rooms, Activity. None of the three exist yet.

What already works

  • The clock, the stations and the timer — including yesterday's fix for the taps that were going missing.
  • Tasks, scope sheet, visit list, office notes, crew, work-auth signing, generate report.
  • Every number on this screen has a real query behind it already.

Read this honestly

Photos are placeholders — no room covers loaded. Neither app font could be embedded here, so both settings show your phone's system font; judge colour and shape, not type. Nothing is tappable.

Why not Field Pro now

One screen in a different design language reads as a bug, not a redesign. Field Pro lands when the whole app moves — and that move is a native Swift rewrite, not a web restyle. Until then this screen matches its neighbours.
